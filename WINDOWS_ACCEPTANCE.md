# NumCalc — ручная приёмка Windows

Версия для проверки: **1.0.0**  
Artifact: `NumCalc-windows-release` из GitHub Actions.

Записывайте фактическую версию Windows, масштаб экрана, тип клавиатуры и результат каждого пункта. Блокирующий дефект означает, что GitHub Release `v1.0.0` не публикуется до исправления.

## 1. Установка и первый запуск

- [ ] SHA-256 из artifact совпадает с `NumCalc.exe.sha256.txt`.
- [ ] EXE запускается без установленного Python.
- [ ] В диспетчере задач один процесс приложения в штатном режиме.
- [ ] Окно «О программе» показывает `NumCalc 1.0.0`.
- [ ] В свойствах EXE указаны имя `NumCalc` и версия `1.0.0`.
- [ ] При отсутствии WebView2 показывается понятная ошибка, а не немой выход.

## 2. Базовая математика

- [ ] `2+3*4` → `14`.
- [ ] `(2+3)*4` → `20`.
- [ ] `2^3^2` → `512`.
- [ ] `sin(30)` в DEG → `0.5`.
- [ ] `9!` → `362880`.
- [ ] `200+10%` → `220`.
- [ ] `1/0` показывает «Деление на ноль».
- [ ] Незавершённое `2+` не создаёт запись истории.

## 3. Ввод и горячие клавиши

- [ ] Ввод остаётся классическим: нет выезда символов, мерцания и визуальной подмены текста.
- [ ] Ввод `*` отображается как `⋅`.
- [ ] `150(5)` отображается как `150⋅(5)` и вычисляется как `750`.
- [ ] `(2)(3)` отображается как `(2)⋅(3)` и вычисляется как `6`.
- [ ] `3100*.,1` вычисляется как `310`.
- [ ] `3100*,1`, `3100⋅,1`, `3100⋅.1` также дают `310`.
- [ ] Точка и запятая работают в русской и английской раскладках.
- [ ] `Ctrl+C` копирует строку вида `3100⋅0,1 = 310` либо эквивалент с текущим разделителем.
- [ ] `Alt+←` открывает «Калькулятор».
- [ ] `Alt+→` открывает «Единицы».
- [ ] Alt+стрелки не запускают навигацию WebView назад/вперёд.
- [ ] Tab открывает палитру функций.
- [ ] Enter фиксирует результат и историю ровно один раз.
- [ ] Backspace, Escape и стрелки работают согласно справке.

## 4. Память и переменные

- [ ] Запись и вставка значений `M0–M9` работают.
- [ ] `span := 6` создаёт сохранённую переменную.
- [ ] `span / 2` даёт `3`.
- [ ] Кнопка `×` удаляет `span` из окна переменных.
- [ ] Удалённая переменная исчезает из подсказок.
- [ ] После перезапуска удалённая переменная не восстанавливается.

## 5. Конвертер единиц

- [ ] `1 тс` → `9.80665 кН`.
- [ ] `1 тс/м²` → `9.80665 кПа`.
- [ ] `1 g` → `9.80665 м/с²`.
- [ ] `0 °C` → `273.15 K`.
- [ ] Состояние категории и пары единиц сохраняется после перезапуска.
- [ ] Результат калькулятора передаётся в «Единицы» только один раз на новую ревизию.
- [ ] `Ctrl+C` в режиме единиц включает исходную и целевую единицы.

## 6. NumLock и фокус

Проверить на встроенной и внешней клавиатуре, если доступны обе.

- [ ] NumLock показывает скрытое окно.
- [ ] NumLock возвращает фокус видимому, но неактивному окну.
- [ ] NumLock скрывает активное окно.
- [ ] Цифровой блок остаётся цифровым после каждого сценария.
- [ ] LED выполняет ожидаемый цикл и остаётся включённым.
- [ ] Долгое удержание NumLock не вызывает многократное дребезжащее переключение.
- [ ] 20 быстрых нажатий не приводят к зависанию или рассинхронизации LED.
- [ ] После сна и пробуждения hook продолжает работать.
- [ ] После блокировки/разблокировки Windows hook продолжает работать.
- [ ] Поведение проверено через RDP, если RDP входит в рабочий сценарий.

## 7. Single-instance и tray

- [ ] Повторный запуск EXE активирует существующее окно.
- [ ] Второй значок в трее не появляется.
- [ ] Второй NumLock-hook не регистрируется.
- [ ] «Показать / Скрыть» работает из трея.
- [ ] Закрытие окна скрывает приложение, не завершает его.
- [ ] «Выйти» завершает процесс и снимает hook.
- [ ] После выхода повторный запуск работает штатно.
- [ ] Автозагрузка не создаёт второй экземпляр при ручном запуске.
- [ ] После перезапуска Explorer приложение остаётся управляемым; поведение значка зафиксировано.

## 8. Хранение и переносимость

### Обычный режим

- [ ] Данные создаются в `%LOCALAPPDATA%\NumCalc\data.json`.
- [ ] История, память, переменные, тема и единицы сохраняются после перезапуска.
- [ ] Старый `numlock-calc-data.json` рядом с EXE мигрирует при отсутствии нового файла.
- [ ] Повреждённый JSON не блокирует запуск.

### Portable-режим

- [ ] `portable.mode` рядом с EXE включает хранение рядом с EXE.
- [ ] `--portable` даёт тот же результат.
- [ ] При папке без права записи показывается предупреждение и используется профиль пользователя.
- [ ] Запуск с флешки и из пути с кириллицей работает.

## 9. Экран и окно

Проверить Windows 10 и Windows 11, где возможно.

- [ ] DPI 100%.
- [ ] DPI 125%.
- [ ] DPI 150%.
- [ ] DPI 200%.
- [ ] Текст не обрезается, элементы не накладываются.
- [ ] Окно перетаскивается за верхнюю область.
- [ ] Интерактивные элементы верхней области не начинают перетаскивание.
- [ ] После отключения второго монитора окно доступно на оставшемся экране.
- [ ] Переходы вкладок и Enter-анимация результата не вызывают дрожание текста или изменение геометрии поля.
- [ ] `prefers-reduced-motion` отключает оставшееся декоративное движение.

## 10. Диагностика

- [ ] Создаётся `%LOCALAPPDATA%\NumCalc\logs\numcalc.log`.
- [ ] Лог содержит версию, Windows, режим hook и путь данных.
- [ ] «Копировать диагностику» помещает читаемый текст в буфер обмена.
- [ ] Искусственная frontend-ошибка попадает в лог.
- [ ] После превышения размера журнал ротируется и не растёт бесконечно.
- [ ] Диагностика не содержит телеметрии и не требует сети.
