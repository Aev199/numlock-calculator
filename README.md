# NumCalc

**NumCalc 1.4.0** — компактный инженерный калькулятор для Windows, который управляется с клавиатуры.

> Калькулятор — идеологическое продолжение [NumLock Calculator](https://nlcalc.narod.ru/) от Владимира Потапова.
>
> NumCalc является самостоятельным open-source проектом и не является официальной новой версией оригинальной программы.

## Основные возможности

- безопасный AST-движок без `eval`;
- арифметика, степени, проценты, факториал, тригонометрия и логарифмы;
- размерностные выражения и инженерные единицы;
- пользовательские переменные, `ans`, память `M0–M9`;
- сохраняемые пользовательские функции с 1–16 параметрами;
- история вычислений;
- конвертер единиц;
- линейная интерполяция;
- палитра функций по **Tab** и автодополнение;
- компактный режим и глобальная клавиша;
- локальное хранение без телеметрии.

## Быстрый старт

```text
2 + 3 * 4
sin(30)
sqrt(144)
9!
200 + 10%
d16
2d20
4d20s200+d16s150
```

**Enter** фиксирует вычисление и добавляет его в историю. Точка и запятая поддерживаются как десятичный разделитель.

## Пользовательские функции

Функция определяется в той же строке, что и обычное выражение:

```text
c(d) := pi*d^2/4
c(20)                 → 314.159265
c(20 mm) to mm2       → 314.159265 мм²
```

Обычный `=` также поддерживается:

```text
c(d) = pi*d^2/4
```

Несколько параметров:

```text
r(a,b) := a*b
r(2,3)                → 6
r(2,5;3,5)            → 8.75
```

Для нескольких десятичных аргументов с десятичной запятой используйте `;` как однозначный разделитель. Функции могут читать текущие переменные, единицы и вызывать другие пользовательские функции. Рекурсия блокируется. Имена встроенных функций, констант и единиц зарезервированы.

После сохранения функция появляется в палитре **Tab** и в окне **«Переменные и функции»**. При вставке `c()` курсор ставится между скобками.

## Площадь арматуры

```text
d16                   → 2.010619 см²
2d20                  → 6.283185 см²
2d20+d16              → 8.293805 см²
d16s150               → 13.404129 см²/м
4d20s200+d16s150      → 76.235982 см²/м
```

Без `s` число перед `d` задаёт количество стержней, результат — суммарная площадь. С `s` задаётся шаг в миллиметрах, результат — площадь армирования на метр. Смешивать термины с шагом и без шага в одной shorthand-записи нельзя.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| **NumLock** или назначенная комбинация | Показать, сфокусировать или скрыть окно |
| **Enter** | Вычислить и добавить в историю |
| **Tab** | Открыть палитру функций |
| **Ctrl+Space** | Автодополнение |
| **↑ / ↓** | История / выбор подсказки |
| **Ctrl+C** | Копировать выражение и результат |
| **Ctrl+H** | История |
| **Alt+← / Alt+→** | Переключить режим |
| **Alt+↑ / Alt+↓** | Компактный / полный интерфейс |
| **Escape** | Закрыть текущий слой, очистить поле или скрыть окно |

## Единицы и интерполяция

Калькулятор понимает единицы внутри выражений и проверяет размерности. Вкладка **«Единицы»** использует тот же реестр величин. Вкладка **«Интерполяция»** выполняет линейную интерполяцию и экстраполяцию по двум точкам.

## Обновления

NumCalc проверяет новые выпуски через 8 секунд после запуска, затем раз в час смотрит общую папку и «Загрузки», а GitHub не чаще раза в сутки. Найденная версия появляется значком в заголовке окна. Проверить вручную можно в **Настройки → Обновления**, в окне «О программе» или в меню значка в трее.

Перед заменой `NumCalc.exe` проверяется SHA-256 из `latest.json` выпуска. Прежняя версия остаётся рядом как `NumCalc.old.exe`, вернуть её можно кнопкой **«Вернуть предыдущую версию»**. Новая версия запускается после перезапуска.

Каналы:

- **Стабильные** — только финальные выпуски;
- **Все сборки (бета)** — также предварительные выпуски с тегами вида `v1.5.0-beta.1`.

Если программе закрыт выход в интернет:

- **браузер**: кнопка «Скачать в браузере» открывает последний выпуск, а NumCalc находит скачанный `NumCalc*.exe` в «Загрузках» и предлагает его установить;
- **общая папка**: положите `NumCalc.exe` и `latest.json` из выпуска в сетевую папку и укажите её в настройках. Администратор может указать папку для всех, положив рядом с `NumCalc.exe` файл `numcalc-update.txt` с путём к ней. Флажок «Выкладывать установленную версию в эту папку» передаёт обновление коллегам.

Проверка через GitHub работает для публичного репозитория: анонимный запрос к API закрытого репозитория вернёт ошибку.

## Установка

1. Откройте [Releases](https://github.com/Aev199/numlock-calculator/releases).
2. Скачайте `NumCalc-1.4.0-windows-x64.zip`.
3. Сверьте SHA-256 архива с `.sha256.txt`.
4. Распакуйте архив и запустите `NumCalc.exe`.

Нужны Windows 10/11 и Microsoft Edge WebView2 Runtime. Установленный Python не требуется.
