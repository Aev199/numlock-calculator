# NumCalc

**NumCalc 1.1.0** — компактный keyboard-first инженерный калькулятор для Windows. Глобальная клавиша показывает окно, возвращает ему фокус или скрывает его, поэтому расчёт остаётся доступным поверх текущей работы.

> Калькулятор — идеологическое продолжение [NumLock Calculator](https://nlcalc.narod.ru/) от Владимира Потапова.
>
> NumCalc является самостоятельным open-source проектом и не является официальной новой версией оригинальной программы.

## Новое в 1.1.0

- единый движок выражений и инженерных единиц с проверкой размерностей;
- сохраняемые формулы с именованными параметрами;
- инженерные профили с константами, набором формул, предпочтительными единицами и форматом результатов;
- настраиваемая глобальная клавиша вместо обязательного NumLock;
- отдельная вкладка линейной интерполяции и экстраполяции;
- три режима: «Калькулятор», «Единицы», «Интерполяция»;
- переключение вкладок через `Alt+←` / `Alt+→` с плавным индикатором и мягкой сменой содержимого;
- переход по истории стрелками `↑` / `↓` с первого нажатия;
- компактный первый запуск с кратким помощником и обновлённой справкой.

Полное описание изменений приведено в [CHANGELOG.md](CHANGELOG.md), а краткое описание выпуска — в [RELEASE_NOTES.md](RELEASE_NOTES.md).

## Основные возможности

- безопасное вычисление выражений без `eval`;
- предварительный результат во время ввода;
- арифметика, скобки, степени, проценты и факториал;
- тригонометрические, логарифмические и вспомогательные функции;
- режимы углов `DEG`, `RAD`, `GRAD`;
- системы счисления `DEC`, `HEX`, `OCT`, `BIN`;
- история, 10 ячеек памяти `M0–M9`, пользовательские переменные и `ans`;
- размерностные выражения и инженерные единицы;
- библиотека формул и инженерные профили;
- конвертер единиц и линейная интерполяция;
- палитра функций по **Tab** и локальное автодополнение;
- парные скобки и цветовая индикация вложенности;
- локальное хранение без телеметрии;
- один экземпляр приложения и управление из системного трея.

Интерфейс построен на **Python + pywebview/WebView2**. Electron и Node.js для запуска не нужны.

## Установка

1. Откройте раздел [Releases](https://github.com/Aev199/numlock-calculator/releases).
2. Скачайте `NumCalc-1.1.0-windows-x64.zip`.
3. Сверьте SHA-256 архива с файлом `.sha256.txt`.
4. Распакуйте архив и запустите `NumCalc.exe`.

Установщик и установленный Python не требуются. Поддерживаются Windows 10/11; необходим Microsoft Edge WebView2 Runtime. Неподписанный EXE может вызвать предупреждение SmartScreen, поэтому загружайте архив только из Releases этого репозитория и сверяйте SHA-256.

## Быстрый старт

```text
2 + 3 * 4
sin(30)
sqrt(144)
9!
200 + 10%
```

Предварительный результат появляется автоматически. **Enter** фиксирует вычисление, сохраняет исходное выражение в историю и подставляет ответ как новое рабочее значение.

При физическом вводе `*` отображается знак `⋅`. Неявное умножение показывается явно:

```text
150(5)   →   150⋅(5)
(2)(3)   →   (2)⋅(3)
```

Поддерживаются точка и запятая как десятичный разделитель. Ошибочный ввод цифрового блока `3100*.,1` нормализуется как `3100⋅0.1`.

## Горячие клавиши

Глобальная клавиша по умолчанию — **NumLock**. В настройках можно назначить другую клавишу или комбинацию; приложение проверяет конфликты и сохраняет выбор между запусками.

| Клавиша | Действие |
|---|---|
| **NumLock** или назначенная комбинация | Показать, сфокусировать или скрыть окно |
| **Enter** | Зафиксировать результат и добавить вычисление в историю |
| **Ctrl+C** | Скопировать выражение и ответ; для отдельного числа — только число |
| **Alt+← / Alt+→** | Циклически переключать три режима |
| **Tab** | Открыть палитру функций |
| **Ctrl+Space** | Открыть автодополнение |
| **↑ / ↓** | Выбрать подсказку или перемещаться по истории |
| **← / →** | Переключить группу в открытой палитре |
| **Escape** | Закрыть подсказку, очистить поле или скрыть пустое окно |

Кнопка закрытия скрывает NumCalc в область уведомлений. Полный выход выполняется через пункт **«Выйти»** в меню трея.

## Размерностные выражения

Калькулятор понимает единицы внутри выражений и проверяет совместимость размерностей:

```text
2 м ⋅ 3 м        → 6 м²
2 кПа + 300 Па   → 2,3 кПа
10 кН / 2 м²     → 5 кПа
2 м + 3 с        → ошибка: разные размерности
```

Поддерживаются базовые и инженерные единицы, включая `мм`, `м`, `м²`, `м³`, `кН`, `тс`, `МПа`, `кН·м`, `тс/м²` и `кН/м³`. Калькулятор и вкладка «Единицы» используют один реестр коэффициентов.

## Формулы и инженерные профили

Кнопка `Σ` открывает библиотеку формул и профилей. Формула хранит название, выражение, параметры и значения по умолчанию:

```text
Название: Давление
Выражение: N / A
Параметры:
N = 1200 кН
A = 10 м2
```

Запуск формулы открывает форму параметров, выполняет размерностный расчёт и добавляет подтверждённый результат в общую историю.

Профиль может содержать:

- набор доступных формул;
- инженерные константы;
- предпочтительные единицы;
- точность, формат числа и десятичный разделитель.

После отключения профиля временно применённые настройки конвертера возвращаются к прежнему состоянию.

## Конвертер единиц

Вкладка **«Единицы»** поддерживает длину, площадь, объём, массу, силу, распределённую силу, момент, давление, удельный вес, скорость, ускорение, время и температуру. Поле принимает простые арифметические выражения со скобками.

## Линейная интерполяция

Вкладка **«Интерполяция»** определяет `y` по двум опорным точкам `(x₀, y₀)` и `(x₁, y₁)`. Расчёт выполняется автоматически после заполнения полей или по кнопке **«Рассчитать»**. За пределами интервала выполняется линейная экстраполяция.

## Формат результатов и история

В настройках доступны автоматическая и инженерная запись чисел, от 3 до 17 значащих знаков, точка или запятая как десятичный разделитель, а также выделение результата после `Enter`.

История сохраняет исходное выражение, нормализованную форму, результат, единицу и время. Стрелки `↑` / `↓` загружают предыдущие выражения сразу, независимо от положения курсора.

## Данные и конфиденциальность

NumCalc не отправляет выражения, историю или настройки в сеть и не содержит телеметрии.

Обычное хранилище:

```text
%LOCALAPPDATA%\NumCalc\data.json
```

Диагностический журнал:

```text
%LOCALAPPDATA%\NumCalc\logs\numcalc.log
```

### Portable-режим

- создайте `portable.mode` рядом с EXE;
- либо запустите `NumCalc.exe --portable`;
- либо установите `NUMCALC_PORTABLE=1`.

Если portable-папка недоступна для записи, приложение использует профиль пользователя и показывает предупреждение.

## Запуск из исходников

Требуются Windows и Python 3.11–3.13.

```bat
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app_keyboard.py
```

## Проверка и сборка

```bat
.venv\Scripts\python -m unittest discover -s tests -v
build.bat
```

Результат:

```text
dist\NumCalc.exe
dist\NumCalc.exe.sha256.txt
```

One-dir и офлайн-сборка поддерживаются скриптами `build_onedir.bat`, `prepare_offline_wheels.bat` и `build_offline.bat`.

GitHub Actions проверяет Python-код, вычислительный движок, API, renderer, tray, хранилище, формулы, единицы и выпускные метаданные. Низкоуровневый hook, WebView2, tray, автозагрузка, DPI и анимации дополнительно проходят ручную проверку по [docs/WINDOWS_ACCEPTANCE.md](docs/WINDOWS_ACCEPTANCE.md).
