# NumLock Calc

Современный клавиатурный калькулятор для Windows, продолжающий идею классического **NumLock Calculator**: NumLock быстро вызывает компактное окно, выражение вычисляется во время ввода, а Enter превращает результат в новое рабочее значение.

Оболочка — **Python + pywebview**. Node.js и Electron не требуются ни для запуска, ни для сборки EXE.

## Возможности

- редактируемое поле выражения и быстрый live-preview;
- Enter заменяет выражение результатом и сохраняет исходное вычисление в историю;
- функции, автоматические скобки, проценты и факториал;
- `DEG / RAD / GRAD` и `DEC / HEX / OCT / BIN`;
- переменные, `ans` и 10 ячеек памяти;
- история с поиском и повторным редактированием;
- командная палитра `Ctrl+K`;
- отдельный режим **«Единицы»**;
- компактное безрамочное окно, системный трей и режим поверх остальных окон;
- классическое поведение NumLock с восстановлением цифрового режима и LED ON.

## Режимы приложения

### Калькулятор

Основной режим предназначен для вычислений, функций, переменных, памяти и истории. Единицы измерения убраны из палитры, чтобы список команд оставался математическим и компактным.

```text
2 + 3 * 4
sin(30)
9!
200 + 10%
span := 6
span / 2
```

### Единицы

Вкладка **«Единицы»** сохраняет общий каркас поля ввода и результата, но вместо истории показывает категорию и picker’ы исходной и целевой единиц.

Поддерживаются:

- длина;
- площадь;
- объём;
- масса;
- время;
- температура;
- сила;
- давление.

Поле принимает только простую арифметику: числа, скобки, `+`, `−`, `×`, `÷`, степень и десятичную запятую. Функции, переменные и записанные в строке единицы не принимаются.

Последний подтверждённый числовой результат калькулятора переносится в режим «Единицы» один раз на новую ревизию. Ручное состояние конвертера не затирается при обычном переключении и сохраняется между запусками.

## Интерфейс и движение

Motion-система построена по принципам современных iOS-приложений: интерфейс сохраняет непрерывность, а анимации объясняют изменение состояния, не задерживая вычисление.

- При ручном вводе само поле получает едва заметный локальный отклик; отдельных светящихся копий символов нет.
- Enter использует morph-переход: старое выражение мягко уходит вверх, новое значение проявляется на его месте.
- Новая строка истории вставляется через FLIP-анимацию: существующие строки плавно освобождают место без полной перерисовки списка.
- Переключатель `Калькулятор / Единицы` оформлен как segmented control с одной перемещающейся капсулой.
- Поле и результат остаются общей сценой, а история и панель единиц заменяют друг друга через matched transition.
- Для актуального WebView2 используется View Transitions API; предусмотрен fallback на Web Animations.
- Нажатия кнопок имеют короткое сжатие и мягкое возвращение без вращений и ярких вспышек.
- `prefers-reduced-motion` отключает декоративное движение.

## Управление

- **NumLock**:
  - показать скрытое окно и выделить выражение;
  - вернуть фокус видимому окну и выделить выражение;
  - скрыть уже активное окно;
  - после управляемого LED OFF → ON цифровой блок остаётся включённым.
- **Enter** — вычислить, подставить результат в поле и сохранить исходное вычисление в историю.
- **Ctrl+K** — открыть палитру команд при любой раскладке.
- **← / →** — переключать группы палитры.
- **↑ / ↓** — выбирать команду или перемещаться по истории.
- **Ctrl+Space** — показать автодополнение.
- **Escape** — закрыть подсказку, очистить поле или скрыть пустое окно.
- **Ctrl+Shift+Q** — аварийный полный выход.

В истории стандартные `DEG` и `DEC` не подписываются. Метка режима появляется только для `RAD`, `GRAD`, `HEX`, `OCT` или `BIN`.

## Безрамочное окно и трей

Системная строка Windows скрыта. Окно перетаскивается за блок с логотипом и названием **NumLock Calc**.

- `—` скрывает окно, не завершая приложение;
- `×` полностью завершает приложение;
- левый клик по значку **N** в трее показывает калькулятор или возвращает ему фокус;
- правый клик открывает меню `Показать калькулятор`, `Скрыть`, `Выйти`.

Скрытие не отключает NumLock-hook и не завершает фоновый процесс.

## Запуск из исходников

Требуется Windows и Python 3.11–3.13.

```bat
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-build.txt
.venv\Scripts\python app_keyboard.py
```

## Сборка

Один EXE:

```bat
build.bat
```

Результат:

```text
dist\NumLockCalc.exe
```

One-dir сборка с одним runtime-процессом приложения:

```bat
build_onedir.bat
```

Результат:

```text
dist\NumLockCalc\NumLockCalc.exe
```

Полностью офлайн:

```bat
prepare_offline_wheels.bat
build_offline.bat
```

## Архитектура

- `calc_engine.py` — безопасный AST-парсер, функции, переменные, память, единицы и форматы;
- `calc_engine_runtime.py` — side-effect-free live-preview и группы команд;
- `app.py` — базовая pywebview-оболочка и JSON-состояние;
- `app_keyboard.py` — точка входа keyboard-first сборки;
- `app_stability.py` — фокус окна и стабилизированный renderer;
- `app_numlock_compat.py` — детерминированный цикл NumLock;
- `app_polish.py` — быстрый preview, автоматические скобки и подключение motion-слоя;
- `app_compact.py` — компактное окно и единый сценарий Enter;
- `app_units_mode.py` — отдельный API и состояние преобразования единиц;
- `app_tray.py` — frameless-окно и системный трей;
- `renderer/script-v2.js` — основной keyboard-first renderer;
- `renderer/polish-v3.js` / `polish-v3.css` — подсказки и компактная шлифовка;
- `renderer/motion-v4.js` / `motion-v4.css` — iOS-подобные morph-, FLIP- и matched-переходы;
- `renderer/units-mode.js` / `units-mode.css` — интерфейс вкладки «Единицы»;
- `tests/` — тесты движка, API, фокуса, NumLock, трея, интерфейса и сборочного сценария.

Данные сохраняются в `numlock-calc-data.json` рядом с EXE.
