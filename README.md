# NumCalc

**NumCalc** — компактный keyboard-first калькулятор для Windows. Клавиша **NumLock** показывает окно, возвращает ему фокус или скрывает его. Выражение вычисляется во время ввода, а **Enter** подставляет результат как новое рабочее значение и сохраняет исходное вычисление в историю.

Оболочка построена на **Python + pywebview/WebView2**. Node.js и Electron не нужны ни для запуска, ни для сборки EXE.

## Возможности

- безопасный AST-движок без `eval`;
- арифметика, скобки, степени, проценты и факториал;
- тригонометрические, логарифмические и вспомогательные функции;
- режимы углов `DEG / RAD / GRAD`;
- системы счисления `DEC / HEX / OCT / BIN`;
- live-preview результата во время ввода;
- история с поиском, копированием, удалением и повторным редактированием;
- 10 ячеек памяти `M0–M9`;
- пользовательские переменные и значение `ans`;
- палитра функций по **Tab** и локальное автодополнение;
- автоматическая парная вставка скобок и цветовая подсветка уровней вложенности;
- отдельный инженерный конвертер единиц;
- безрамочное окно поверх остальных окон;
- системный трей, автозагрузка Windows и встроенная справка;
- управляемый NumLock-hook: цифровой режим клавиатуры остаётся включённым.

## Режимы

### Калькулятор

Основной режим предназначен для обычных вычислений, функций, памяти, переменных и истории.

Примеры:

```text
2 + 3 * 4
sin(30)
sqrt(144)
9!
200 + 10%
span := 6
span / 2
```

Поддерживаемые группы функций выводятся в палитре в фиксированном порядке.

**Тригонометрия:**

```text
sin, cos, tan, atan, asin, acos
```

**Степени и логарифмы:**

```text
sqrt, exp, log, ln, log10, fact, cbrt
```

При вводе открывающей скобки автоматически добавляется закрывающая, а каретка остаётся внутри. Вложенные пары скобок подсвечиваются разными цветами.

### Единицы

Вкладка **«Единицы»** использует то же поле ввода и результата, а вместо истории показывает категорию и исходную/целевую единицы.

Поддерживаются:

- линейные размеры;
- площади;
- объёмы;
- масса;
- силы;
- распределённые силы;
- моменты сил;
- скорости;
- ускорения;
- давления;
- удельный вес;
- время;
- температура.

В инженерных категориях доступны в том числе `кгс`, `тс`, `кН`, `МН`, `кгс/м`, `тс/м`, `кН·м`, `кгс/м²`, `тс/м²`, `кН/м³` и другие единицы. В интерфейсе отображаются русские обозначения; внутренние расчётные ключи пользователю не показываются.

Поле конвертера принимает простую арифметику: числа, скобки, `+`, `−`, `×`, `÷`, степень и десятичную запятую. Функции и переменные внутри выражения в режиме единиц не используются.

Последний подтверждённый числовой результат калькулятора передаётся в режим «Единицы» один раз на новую ревизию. Ручное состояние конвертера сохраняется между переключениями и перезапусками.

## Память и переменные

### Память

Доступно 10 ячеек: `M0–M9`.

В окне памяти можно:

- записать текущее выражение в выбранную ячейку;
- вставить сохранённое значение в поле;
- использовать значения памяти повторно в вычислениях.

### Переменные

Переменная создаётся присваиванием:

```text
width = 12.5
height := 3
area = width * height
```

Сохранённые переменные доступны в палитре функций и в отдельном окне переменных. Значение `ans` содержит последний подтверждённый результат.

## Управление

- **NumLock** — показать скрытое окно, вернуть фокус видимому окну или скрыть активное.
- **Enter** — вычислить выражение, подставить результат и сохранить исходное вычисление в историю.
- **Tab** — открыть палитру функций из поля выражения.
- **← / →** — переключать группы палитры.
- **↑ / ↓** — выбирать функцию или перемещаться по истории.
- **Ctrl+Space** — показать автодополнение.
- **Escape** — закрыть подсказку, очистить поле или скрыть пустое окно.
- **—** в верхней панели — скрыть приложение в область уведомлений.

В верхней панели нет кнопки полного выхода. Закрытие окна также только скрывает NumCalc. Полный выход выполняется через контекстное меню значка в трее.

## Системный трей

Контекстное меню NumCalc содержит:

- **Показать / Скрыть**;
- **Автозагрузка Windows**;
- **Справка**;
- **О программе**;
- **Выйти**.

Автозагрузка включается для текущего пользователя через стандартный раздел Windows:

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
```

Во встроенной справке описаны основные вычисления, палитра функций, история, режим единиц, память, переменные и управление окном.

## Интерфейс

- Перетаскивать окно можно за всю верхнюю область, кроме интерактивных кнопок.
- Поле ввода и результат не пересоздаются при смене режима.
- История и панель единиц постоянно находятся в DOM.
- Переключение между режимами выполняется направленной горизонтальной анимацией.
- Анимация Enter работает через отдельные визуальные слои, не меняя геометрию `textarea`.
- Обычный ввод символов остаётся нативным и не перехватывается декоративной анимацией.

## Архитектура

### Python

- `calc_engine.py` — безопасный парсер и вычислительное ядро;
- `calc_engine_runtime.py` — preview, диагностика и каталог функций;
- `app.py` — базовый API и JSON-хранилище;
- `app_window.py` — фокус, видимость и активация окна;
- `app_numlock_compat.py` — низкоуровневый NumLock-hook и LED-цикл;
- `app_tray.py` — безрамочное окно, трей, автозагрузка, справка и жизненный цикл;
- `unit_conversion.py` — каталог инженерных единиц и безопасная арифметика;
- `app_units_backend.py` — backend API конвертера и передача результата;
- `app_renderer.py` — единственный сборщик финального HTML;
- `app_keyboard.py` — рабочая точка входа.

### Frontend

- `renderer/app-shell.html` — постоянная разметка приложения;
- `renderer/app-shell.css` — основная система оформления;
- `renderer/app-shell-motion.css` — переходы и Enter-анимация;
- `renderer/app-shell-ux.css` — UX-слой скобок и дополнительных состояний;
- `renderer/app-shell-v2.part00.js … part08.js` — части единого IIFE-контроллера;
- `renderer/app-shell-v2.ux.js` — Tab-палитра, порядок функций и подсветка скобок.

`app_renderer.py` объединяет CSS и JavaScript в один inline-документ через заранее заданные placeholders. Рабочая точка входа не использует старые renderer-патчи `app_polish`, `app_compact`, `app_stability` и `app_units_mode`.

## Запуск из исходников

Требуется Windows и Python 3.11–3.13.

```bat
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-build.txt
.venv\Scripts\python app_keyboard.py
```

## Сборка

Один EXE:

```bat
build.bat
```

Результат:

```text
dist\NumLockCalc.exe
```

Имя исполняемого файла пока сохранено для совместимости со старыми сборочными сценариями; видимое название приложения — **NumCalc**.

One-dir сборка:

```bat
build_onedir.bat
```

Полностью офлайн:

```bat
prepare_offline_wheels.bat
build_offline.bat
```

Пользовательские данные сохраняются в файле:

```text
numlock-calc-data.json
```

Файл располагается рядом с EXE.
