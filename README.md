# NumLock Calc

Компактный инженерный калькулятор для Windows, который показывается и скрывается глобальной клавишей **NumLock**. Основная оболочка проекта — **Python + pywebview**; Node.js и Electron для запуска и сборки не нужны.

## Возможности

- стандартный и инженерный режимы;
- выражения со скобками, степенями, функциями и научной записью;
- редактирование выражения с установкой курсора и выделением любого участка;
- загрузка полного исходного выражения из истории;
- тригонометрические функции в градусах;
- калькуляторный процент (`200 + 10% = 220`);
- память `MC`, `MR`, `M+`, `M-`;
- история вычислений и светлая/тёмная тема;
- конвертер давления, площади, силы, объёма, длины, массы и температуры;
- окно всегда находится поверх остальных окон;
- **NumLock** показывает или скрывает окно, но остаётся включённым;
- закрытие системной кнопкой скрывает окно, кнопка `×` внутри приложения полностью завершает процесс;
- данные хранятся в `numlock-calc-data.json` рядом с EXE.

## Быстрый запуск из исходников

Требуется Windows и Python 3.11–3.13.

```bat
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-build.txt
.venv\Scripts\python app.py
```

## Обычная сборка при доступе Python к интернету

```bat
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-build.txt
.venv\Scripts\python -m unittest tests/test_storage.py
.venv\Scripts\python -m PyInstaller --noconfirm --clean NumLockCalc.spec
```

Node.js нужен только для необязательного запуска JavaScript-тестов:

```bat
node tests/test_calc_core.js
```

Результат: `dist\NumLockCalc.exe`.

## Полностью офлайн-сборка EXE

PyInstaller не является кросс-компилятором: Windows EXE нужно собирать на Windows. Если Python также не имеет доступа к интернету, заранее подготовьте wheel-файлы.

На Windows-машине с интернетом:

```bat
prepare_offline_wheels.bat
```

Перенесите весь проект вместе с папкой `wheelhouse`, затем на закрытой машине запустите:

```bat
build_offline.bat
```

## Управление

- **NumLock** — показать или скрыть окно, не меняя состояние цифрового блока;
- клик по истории — загрузить полное выражение для редактирования;
- клик в строке выражения — установить курсор в нужное место;
- **Enter** — вычислить;
- **Escape** или **Delete** — очистить;
- **Backspace** — удалить символ слева от курсора;
- **Ctrl+Shift+Q** — аварийный полный выход;
- кнопка `×` в шапке приложения — полный выход.

Можно выделить часть выражения и применить к ней инженерную функцию: например, выделить `30` и нажать `sin`.

## Структура

- `app.py` — окно pywebview, глобальный перехват NumLock и JSON-хранилище;
- `renderer/calc-core.js` — парсер и вычислительное ядро;
- `renderer/script.js` — редактируемый интерфейс, история, темы и конвертер;
- `tests/test_calc_core.js` — тесты вычислительного ядра без npm-пакетов;
- `tests/test_storage.py` — тесты хранилища, NumLock и упаковки HTML;
- `NumLockCalc.spec` — конфигурация PyInstaller.

## Примечание о WebView2

На актуальных Windows 10/11 WebView2 обычно уже установлен. На урезанной или старой системе без WebView2 Runtime его необходимо установить отдельно.
