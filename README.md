# NumCalc

**NumCalc** — компактный keyboard-first калькулятор для Windows. Клавиша **NumLock** показывает окно, возвращает ему фокус или скрывает его; вычисление остаётся доступным поверх текущей работы и не требует переключения на отдельное полноразмерное приложение.

> Калькулятор — идеологическое продолжение [NumLock Calculator](https://nlcalc.narod.ru/) от Владимира Потапова.
>
> NumCalc является самостоятельным open-source проектом и не является официальной новой версией оригинальной программы.

[Скачать последнюю версию](https://github.com/Aev199/numlock-calculator/releases/latest) · [Сообщить об ошибке](https://github.com/Aev199/numlock-calculator/issues) · [Лицензирование](LICENSING.md)

## Что умеет NumCalc

- безопасно вычисляет выражения без `eval`;
- показывает предварительный результат во время ввода;
- поддерживает арифметику, скобки, степени, проценты и факториал;
- содержит тригонометрические, логарифмические и вспомогательные функции;
- работает в режимах углов `DEG`, `RAD`, `GRAD`;
- поддерживает системы счисления `DEC`, `HEX`, `OCT`, `BIN`;
- хранит историю, 10 ячеек памяти `M0–M9`, пользовательские переменные и `ans`;
- открывает палитру функций по **Tab** и предлагает локальное автодополнение;
- автоматически добавляет парную скобку и различает уровни вложенности цветом;
- включает отдельный инженерный конвертер единиц;
- хранит данные локально и не содержит телеметрии;
- работает в одном экземпляре и управляется из системного трея.

Интерфейс построен на **Python + pywebview/WebView2**. Electron и Node.js для запуска не нужны.

## Установка

1. Откройте раздел [Releases](https://github.com/Aev199/numlock-calculator/releases).
2. Скачайте архив `NumCalc-<версия>-windows-x64.zip`.
3. Сверьте SHA-256 архива с опубликованным файлом `.sha256.txt`.
4. Распакуйте архив в обычную папку и запустите `NumCalc.exe`.

Установщик не требуется. Для работы нужен Windows 10/11 и Microsoft Edge WebView2 Runtime. На актуальных версиях Windows WebView2 обычно уже установлен.

Windows может показать предупреждение SmartScreen для нового неподписанного приложения. Проверяйте, что архив загружен именно из Releases этого репозитория, и сверяйте SHA-256.

## Быстрый старт

Введите выражение:

```text
2 + 3 * 4
sin(30)
sqrt(144)
9!
200 + 10%
```

Предварительный результат появится автоматически. **Enter** фиксирует вычисление, сохраняет исходное выражение в историю и подставляет ответ как новое рабочее значение.

При физическом вводе `*` в поле отображается знак `⋅`. Неявное умножение показывается явно:

```text
150(5)   →   150⋅(5)
(2)(3)   →   (2)⋅(3)
```

Поддерживаются точка и запятая как десятичный разделитель. Типичный ошибочный ввод цифрового блока `3100*.,1` нормализуется как `3100⋅0.1`.

### Функции

**Тригонометрия:**

```text
sin, cos, tan, atan, asin, acos
```

**Степени и логарифмы:**

```text
sqrt, cbrt, exp, log, ln, log10, fact
```

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| **NumLock** | Показать скрытое окно, вернуть фокус видимому или скрыть активное |
| **Enter** | Зафиксировать результат и записать вычисление в историю |
| **Ctrl+C** | Скопировать выражение и ответ; для отдельного числа — только число |
| **Alt+← / Alt+→** | Переключить «Калькулятор» и «Единицы» |
| **Tab** | Открыть палитру функций |
| **Ctrl+Space** | Открыть автодополнение |
| **↑ / ↓** | Выбрать подсказку или перемещаться по истории |
| **← / →** | Переключить группу в открытой палитре |
| **Escape** | Закрыть подсказку, очистить поле либо скрыть пустое окно |

Кнопка закрытия скрывает NumCalc в область уведомлений. Полный выход выполняется через пункт **«Выйти»** в меню значка трея.

## Память и переменные

Доступно 10 ячеек памяти `M0–M9`.

Переменные создаются присваиванием:

```text
width = 12.5
height := 3
area = width * height
```

Сохранённые переменные доступны в палитре и отдельном окне. `ans` содержит последний подтверждённый результат.

## Конвертер единиц

Вкладка **«Единицы»** преобразует:

- длину, площадь и объём;
- массу, силу, распределённую силу и момент;
- давление и удельный вес;
- скорость и ускорение;
- время и температуру.

Доступны инженерные единицы, включая `кгс`, `тс`, `кН`, `МН`, `тс/м²`, `кН·м`, `кН/м³` и другие. Поле конвертера принимает простую арифметику со скобками.

## Данные и конфиденциальность

NumCalc не отправляет выражения, историю или настройки в сеть и не содержит телеметрии.

Обычное хранилище:

```text
%LOCALAPPDATA%\NumCalc\data.json
```

Локальный диагностический журнал:

```text
%LOCALAPPDATA%\NumCalc\logs\numcalc.log
```

Диагностика включает сведения о версии и среде, путь хранилища и последние ошибки. Содержимое копируется только по явной команде пользователя.

### Portable-режим

Используйте один из способов:

- создайте пустой файл `portable.mode` рядом с EXE;
- запустите `NumCalc.exe --portable`;
- установите `NUMCALC_PORTABLE=1`.

В portable-режиме данные сохраняются рядом с EXE. Если папка недоступна для записи, приложение переключается на профиль пользователя и показывает предупреждение.

## Запуск из исходников

Требуются Windows и Python 3.11–3.13.

```bat
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app_keyboard.py
```

## Проверка и сборка

Полный набор тестов:

```bat
.venv\Scripts\python -m unittest discover -s tests -v
```

One-file сборка:

```bat
build.bat
```

Результат:

```text
dist\NumCalc.exe
dist\NumCalc.exe.sha256.txt
```

One-dir и офлайн-сборка также поддерживаются скриптами `build_onedir.bat`, `prepare_offline_wheels.bat` и `build_offline.bat`.

GitHub Actions проверяет Python-код, вычислительный движок, API, renderer, tray, хранилище и конвертер единиц, затем собирает Windows EXE и проверяет его метаданные. Низкоуровневый NumLock-hook, WebView2, tray, автозагрузка и DPI дополнительно проходят ручную приёмку по [docs/WINDOWS_ACCEPTANCE.md](docs/WINDOWS_ACCEPTANCE.md).
