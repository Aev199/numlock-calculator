# NumLock Calc

Современный клавиатурный калькулятор для Windows, продолжающий идею классического **NumLock Calculator**: быстро вызвать окно клавишей NumLock, набрать выражение, получить результат и при необходимости сразу вставить его в предыдущую программу.

Основная оболочка — **Python + pywebview**. Node.js и Electron не требуются ни для запуска, ни для сборки EXE.

## Текущая итерация: keyboard-first

В интерфейсе больше нет экранной цифровой клавиатуры. Основные элементы:

- полноценное редактируемое поле выражения;
- live-preview результата во время ввода;
- автоматические скобки для функций с установкой курсора внутрь;
- история с повторным редактированием выражений;
- поиск по истории;
- сгруппированная командная палитра (`Ctrl+K`);
- переключение групп палитры стрелками `← / →`;
- 10 ячеек памяти `M0…M9`;
- именованные переменные (`span := 6 m`);
- режимы углов `DEG / RAD / GRAD`;
- форматы целых чисел `DEC / HEX / OCT / BIN`;
- конвертация единиц непосредственно в выражении;
- копирование результата и автоматическая вставка в предыдущее окно;
- безрамочное окно с собственной верхней панелью;
- значок в системном трее;
- окно всегда поверх остальных;
- классическое поведение NumLock: клавиша вызывает приложение, индикатор кратко гаснет и автоматически возвращается во включённое состояние.

## Примеры выражений

```text
2 + 3 * 4
sin(30)
9!
200 + 10%
250 kPa to MPa
10 kN / (2 m2) to kPa
20 degC to K
span := 6 m
span / 2 to cm
```

Поддерживаются привычные символы `×`, `÷`, `−`, десятичная запятая и `^` для степени.

## Управление

- **NumLock**:
  - если калькулятор скрыт — показать и выделить всё выражение;
  - если окно видно, но фокус находится в другой программе — вернуть фокус и выделить всё выражение;
  - если калькулятор уже активен — скрыть его;
  - физические события NumLock поглощаются приложением;
  - краткое гашение индикатора воспроизводится управляемой последовательностью OFF → ON;
  - цифровой блок после цикла остаётся в цифровом режиме;
- **Enter** — вычислить и добавить в историю;
- **Ctrl+Enter** — вычислить, вставить результат в предыдущее окно и скрыть калькулятор;
- **Ctrl+K** — открыть палитру при любой раскладке клавиатуры;
- **← / →** в палитре — переключить группу команд;
- **↑ / ↓** в палитре — выбрать команду;
- **Ctrl+Space** — показать автодополнение;
- **Up / Down** в начале или конце строки — навигация по истории;
- **Escape** — закрыть подсказку, очистить выражение или скрыть пустое окно;
- **Ctrl+Shift+Q** — аварийный полный выход.

При повторном показе или возврате фокуса через NumLock всё текущее выражение выделяется, чтобы следующий ввод сразу заменил его. Внутренние действия интерфейса сохраняют обычную позицию курсора.

### Безрамочное окно

Системная строка заголовка Windows скрыта. Окно перетаскивается за блок с логотипом и названием **NumLock Calc** в левой части верхней панели. Кнопки справа остаются обычными элементами управления:

- `—` — скрыть окно, не завершая приложение;
- `×` — полностью завершить приложение.

Системное окно создаётся с параметрами `frameless=True`, `easy_drag=False` и `shadow=True`. Для перетаскивания используется отдельная pywebview drag-region, поэтому кнопки управления не превращаются в область захвата окна.

### Системный трей

После запуска появляется значок **N** в области уведомлений Windows:

- левый клик — показать калькулятор или вернуть ему фокус;
- правый клик — меню `Показать калькулятор`, `Скрыть`, `Выйти`;
- скрытие окна не отключает NumLock-hook и не завершает фоновый процесс;
- команда `Выйти` удаляет значок из трея и полностью завершает приложение.

Значок запускается непосредственно перед GUI-loop, когда объект pywebview-окна уже зарегистрирован, и останавливается при любом завершении приложения. Он может автоматически оказаться в скрытой части области уведомлений Windows; его можно перетащить на видимую часть панели задач стандартными средствами Windows.

## Запуск из исходников

Требуется Windows и Python 3.11–3.13.

```bat
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-build.txt
.venv\Scripts\python app_keyboard.py
```

## Сборка одним EXE

```bat
build.bat
```

Результат:

```text
dist\NumLockCalc.exe
```

Это PyInstaller `onefile`. Такой EXE распаковывает приложение во временную папку и запускает рабочий дочерний процесс, поэтому в диспетчере задач обычно видны два процесса `NumLockCalc`. Это штатное поведение упаковки, а не два экземпляра калькулятора.

## Сборка с одним runtime-процессом

```bat
build_onedir.bat
```

Результат:

```text
dist\NumLockCalc\NumLockCalc.exe
```

Это PyInstaller `onedir`: рядом с EXE находится папка зависимостей, зато на Windows сам NumLock Calc работает одним процессом. Системный WebView2 при этом может создавать собственные процессы Microsoft Edge WebView2 Runtime.

## Полностью офлайн-сборка

На машине с интернетом и той же версией Python:

```bat
prepare_offline_wheels.bat
```

Перенесите проект вместе с папкой `wheelhouse`, затем на закрытой машине выполните:

```bat
build_offline.bat
```

## Архитектура

- `calc_engine.py` — безопасный AST-парсер, функции, переменные, память, единицы и форматы;
- `calc_engine_runtime.py` — side-effect-free live-preview, форматирование и группы команд;
- `app_keyboard.py` — точка входа keyboard-first сборки;
- `app.py` — базовая pywebview-оболочка, JSON-состояние, буфер обмена и вставка;
- `app_stability.py` — фокус окна и стабилизированный renderer;
- `app_numlock_compat.py` — детерминированный цикл NumLock и восстановление состояния ON;
- `app_polish.py` — быстрый live-preview, автоматические скобки и анимации;
- `app_tray.py` — безрамочное окно, drag-region и системный трей;
- `renderer/index-v2.html` — стабилизированная keyboard-first разметка;
- `renderer/script-v2.js` — редактор, выделение при возврате, live-preview, история и сгруппированная палитра;
- `renderer/style-v2.css` — светлая/тёмная тема и группы команд;
- `renderer/polish-v3.js` и `renderer/polish-v3.css` — слой отзывчивости и анимаций;
- `tests/test_calc_engine.py` — тесты вычислений и единиц;
- `tests/test_app.py` — тесты API, хранения и регистрации горячих клавиш;
- `tests/test_stability.py` — тесты фокуса и NumLock;
- `tests/test_polish.py` — тесты слоя шлифовки renderer;
- `tests/test_tray.py` — тесты frameless-параметров и tray-shell;
- `NumLockCalc.spec` — onefile-сборка;
- `NumLockCalc-folder.spec` — onedir-сборка.

## Ограничения текущего этапа

Это стабильный проход новой архитектуры, а не полный клон старого NLCalc. Следующие этапы: даты и время, градусы-минуты-секунды, пользовательские функции, более полные логические/битовые операции, настройка горячих клавиш и расширенная работа с буфером обмена.

Данные сохраняются в `numlock-calc-data.json` рядом с EXE.
