# NumLock Calc — Portable-версия

Современный клон NumLock Calculator с интерфейсом 2026 года.

## Возможности

- 🧮 Инженерный и стандартный режимы
- 🌓 Тёмная / светлая тема
- 📜 История вычислений в основном окне (над дисплеем)
- 🔄 Конвертер инженерных единиц (давление, площадь, сила, объём, длина, масса, температура)
- 🔑 Глобальный хук NumLock — показать/скрыть окно
- 💾 Сворачивается в системный трей
- 🚀 Portable — можно носить на флешке, не требует установки

## Сборка Portable .exe

### Требования
- Node.js 18+ (https://nodejs.org)
- npm (входит в Node.js)

### Шаги

```bash
# 1. Распаковать архив, зайти в папку
cd numlock-calculator

# 2. Установить зависимости
npm install

# 3. Собрать portable-версию (один exe-файл)
npm run dist:portable
```

Готовый файл: `dist/NumLockCalc_Portable.exe`

Просто скопируйте его на флешку и запускайте на любом Windows-компьютере. Никаких следов в реестре, все данные (история, тема) хранятся локально в localStorage Electron.

## Сборка установщика (если нужен)

```
npm run dist
```

В папке `dist/` появится установщик `NumLock Calc Setup.exe` и/или portable-версия.

## Разработка (запуск без сборки)

```
npm start
```

## Управление

- **NumLock** — глобально показать/скрыть калькулятор
- **Клик по иконке в трее** — показать/скрыть
- **ПКМ по иконке в трее** — меню (автозапуск, выход)
- **Enter** — вычислить
- **Escape** — сброс
- **Backspace** — удалить последний символ
