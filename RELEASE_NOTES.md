# NumCalc 1.3.0

NumCalc 1.3.0 добавляет быстрые пользовательские функции прямо в строке калькулятора, инженерный shorthand площади арматуры и исправляет отображение длинных выражений.

NumCalc — самостоятельный open-source проект и продолжение идей [NumLock Calculator](https://nlcalc.narod.ru/) Владимира Потапова.

## Главное в выпуске

- `c(d) := pi*d^2/4`, затем `c(20)`;
- несколько параметров: `r(a,b) := a*b`, затем `r(2,3)`;
- функции сохраняются, появляются в Tab-палитре и в окне «Переменные и функции»;
- при вставке функции создаются скобки и курсор ставится внутрь;
- функции работают через безопасный AST-движок без `eval`, поддерживают переменные, единицы и вложенные пользовательские вызовы;
- `d16`, `2d20`, `2d20+d16` возвращают площадь стержней в `cm2`;
- `d16s150`, `4d20s200+d16s150` возвращают площадь армирования на метр в `cm2/m`;
- длинные выражения не переносятся и прокручиваются горизонтально;
- **старые отдельные «Формулы» и «Профили» удалены**. Их backend/API, drawer и справка больше не используются.

## Пользовательские функции

```text
c(d) := pi*d^2/4
c(20)                 → 314.159265
c(20 mm) to mm2       → 314.159265 mm2

r(a,b) := a*b
r(2,3)                → 6
r(2,5;3,5)            → 8.75
```

Обычный `=` также поддерживается при определении. Для нескольких аргументов с десятичной запятой используйте `;` как однозначный разделитель.

Параметры существуют только во время вызова и не перезаписывают сохранённые переменные. Пользовательские функции могут вызывать другие пользовательские функции; рекурсия блокируется. Имена встроенных функций, констант и единиц зарезервированы.

## Площадь арматуры

```text
d16                   → 2.010619 cm2
2d20                  → 6.283185 cm2
2d20+d16              → 8.293805 cm2
d16s150               → 13.404129 cm2/m
4d20s200+d16s150      → 76.235982 cm2/m
```

Термины с шагом и без шага нельзя смешивать в одном shorthand-выражении.

## Длинные выражения

Основное поле сохраняет выражение на одной физической строке. При нехватке ширины используется горизонтальная прокрутка; цветной bracket-overlay следует тем же метрикам.

## Установка

Скачайте `NumCalc-1.3.0-windows-x64.zip`, проверьте SHA-256, распакуйте и запустите `NumCalc.exe`. Установщик и установленный Python не требуются.

Перед публикацией выпуск должен пройти автоматические тесты, Windows-сборку и ручную приёмку по `docs/WINDOWS_ACCEPTANCE.md`.
