# NumCalc 1.3.0

NumCalc 1.3.0 добавляет быстрый инженерный ввод площади арматуры и исправляет отображение длинных выражений в основном калькуляторе.

NumCalc — самостоятельный open-source проект и продолжение идей [NumLock Calculator](https://nlcalc.narod.ru/) Владимира Потапова.

## Главное в выпуске

- добавлен компактный синтаксис площади арматуры вида `d20s200`, `4d20s200` и `4d20s200+d16s150`;
- `d` задаёт диаметр стержня в миллиметрах, `s` — шаг в миллиметрах, число перед `d` — количество одинаковых слоёв/наборов;
- расчёт выполняется для полосы шириной 1 м и возвращается как площадь в `см²`;
- длинные выражения больше не переносятся на следующую строку внутри редактора: поле прокручивается горизонтально, поэтому длинные числа не разрываются визуально;
- сохранены существующие возможности 1.2.0: размерностный движок, единицы, интерполяция, compact, переменные, память, формулы и профили.

## Площадь арматуры

Примеры:

```text
d20s200
4d20s200
4d20s200+d16s150
```

Запись

```text
4d20s200+d16s150
```

означает четыре одинаковых набора Ø20 с шагом 200 мм плюс один набор Ø16 с шагом 150 мм. NumCalc использует площадь круглого стержня `πd²/4`, определяет количество стержней на одном метре по шагу и суммирует составляющие.

Для этого примера результат:

```text
76.235982 cm2
```

при стандартной точности 6 знаков после запятой. Настройки точности и десятичного разделителя продолжают применяться как к обычному результату.

Арматурный shorthand распознаётся только тогда, когда всё выражение состоит из корректных арматурных терминов, соединённых `+`. Обычные математические выражения и пользовательские переменные не переопределяются.

## Длинные выражения

Основное поле калькулятора теперь сохраняет выражение на одной физической строке. Если ширины окна недостаточно, редактор прокручивается по горизонтали. Это исключает перенос отдельных длинных чисел на следующую строку и сохраняет синхронизацию цветных скобок с текстом.

## Установка

Скачайте `NumCalc-1.3.0-windows-x64.zip`, проверьте SHA-256, распакуйте архив и запустите `NumCalc.exe`. Установщик и установленный Python не требуются.

Архив содержит:

- `NumCalc.exe` и его SHA-256;
- лицензию NumCalc;
- уведомления и тексты лицензий фактически включённых сторонних компонентов;
- `RELEASE_NOTES.md`;
- архив исходного пакета `pystray 0.19.5`, необходимый для соблюдения LGPL.

## Совместимость и ограничения

- Windows 10/11;
- Microsoft Edge WebView2 Runtime;
- EXE не подписан коммерческим сертификатом, поэтому SmartScreen может показать предупреждение;
- поведение глобальной клавиши может зависеть от RDP, утилит клавиатуры и других программ с глобальными hooks.

Перед публикацией выпуск должен пройти автоматические тесты, Windows-сборку и ручную приёмку по `docs/WINDOWS_ACCEPTANCE.md`.

Полный список изменений находится в [CHANGELOG.md](CHANGELOG.md).
