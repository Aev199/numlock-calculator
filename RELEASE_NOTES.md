# NumCalc 1.4.3

## Исправлено

- скачанная вручную бета в «Загрузках» больше не выдаёт себя за финальную версию и не предлагается по кругу: NumCalc читает версию файла вместе с суффиксом `-beta`;
- NumCalc сравнивает все источники обновлений (GitHub, общую папку, «Загрузки») и предлагает самую новую версию; при равных выбирает выпуск с GitHub.

Обновление придёт само в версиях 1.4.0 и новее. Если NumCalc предлагает по кругу файл из «Загрузок», удалите `NumCalc*.exe` оттуда и нажмите «Проверить сейчас».
