# NumCalc 1.3.0

NumCalc 1.3.0 добавляет быстрый инженерный ввод площади арматуры, лёгкие пользовательские функции прямо в строке калькулятора и исправляет отображение длинных выражений.

NumCalc — самостоятельный open-source проект и продолжение идей [NumLock Calculator](https://nlcalc.narod.ru/) Владимира Потапова.

## Главное в выпуске

- добавлены лёгкие пользовательские функции по аналогии с переменными: `c(d) := pi*d^2/4`, вызов `c(20)`;
- пользовательская функция может иметь несколько параметров: `r(a,b) := a*b`, вызов `r(2,3)`;
- функции сохраняются между запусками, появляются в `Tab`-каталоге и управляются в общем окне «Переменные и функции»;
- функции вычисляются существующим безопасным AST-движком NumCalc без `eval` и могут использовать переменные, единицы и другие пользовательские функции;
- добавлен компактный синтаксис площади арматуры без шага: `d16`, `2d20`, `2d20+d16`;
- для записи без `s` результат является суммарной площадью указанных стержней и выводится в `см²`;
- добавлен синтаксис армирования с шагом: `d16s150`, `4d20s200+d16s150`;
- при наличии `s` результат является площадью армирования на метр и выводится в `см²/м`;
- термины с шагом и без шага намеренно нельзя смешивать в одной shorthand-записи;
- длинные выражения больше не переносятся на следующую строку внутри редактора: поле прокручивается горизонтально, поэтому длинные числа не разрываются визуально;
- сохранены существующие возможности 1.2.0: размерностный движок, единицы, интерполяция, compact, переменные, память, сохранённые формулы и профили.

## Быстрые пользовательские функции

Функцию можно определить прямо там же, где выполняются обычные вычисления:

```text
c(d) := pi*d^2/4
c(20)                 → 314.159265
c(20 mm) to mm2       → 314.159265 mm2
```

Поддерживается и обычный знак `=`:

```text
c(d) = pi*d^2/4
```

Параметров может быть несколько:

```text
r(a,b) := a*b
r(2,3)                → 6
```

NumCalc учитывает количество параметров при разборе запятых. Поэтому для функции с одним параметром `c(2,5)` означает десятичное число `2.5`, а для двухпараметрной `r(2,3)` — два аргумента. Если одновременно нужны десятичные запятые и несколько аргументов, точка с запятой служит однозначным разделителем:

```text
r(2,5;3,5)            → 8.75
```

Тело функции вычисляется тем же безопасным AST-движком, что и обычное выражение. Оно может обращаться к текущим пользовательским переменным и вызывать другие быстрые функции. Параметры существуют только на время вызова и не перезаписывают одноимённые сохранённые переменные. Прямые и косвенные рекурсивные вызовы блокируются.

Имена встроенных функций, констант и единиц нельзя переопределять как пользовательские функции. До 16 параметров на функцию и до 100 пользовательских функций сохраняются в `engine_state` вместе с переменными и памятью.

## Площадь арматуры

### Без шага

```text
d16       → 2.010619 cm2
2d20      → 6.283185 cm2
2d20+d16  → 8.293805 cm2
```

`d16` означает площадь одного стержня Ø16 мм. Число перед `d` задаёт количество одинаковых стержней. Площади рассчитываются по `πd²/4` и суммируются.

### С шагом

```text
d16s150             → 13.404129 cm2/m
4d20s200+d16s150    → 76.235982 cm2/m
```

`d16s150` означает Ø16 с шагом 150 мм. Число перед `d` задаёт количество одинаковых слоёв/наборов с тем же диаметром и шагом. NumCalc делит площадь стержня на шаг и приводит результат к `см²/м`.

Настройки точности и десятичного разделителя продолжают применяться как к обычному результату.

Арматурный shorthand распознаётся только тогда, когда всё выражение состоит из корректных арматурных терминов, соединённых `+`. Все термины должны быть одного типа: либо без шага, либо с шагом. Обычные математические выражения и пользовательские переменные не переопределяются.

## Длинные выражения

Основное поле калькулятора теперь сохраняет выражение на одной физической строке. У `textarea` отключён soft-wrap, а CSS запрещает перенос токенов. Если ширины окна недостаточно, редактор прокручивается по горизонтали. Это исключает перенос отдельных длинных чисел на следующую строку и сохраняет синхронизацию цветных скобок с текстом.

## Установка

Скачайте `NumCalc-1.3.0-windows-x64.zip`, проверьте SHA-256, распакуйте архив и запустите `NumCalc.exe`. Установщик и установленный Python не требуются.

Архив содержит:

- `NumCalc.exe` и его SHA-256;
- лицензию NumCalc;
- уведомления и тексты лицензий фактически включённых сторонних компонентов;
- `RELEASE_NOTES.md`;
- архив исходного пакета `pystray 0.19.5`, необходимый для соблюдения LGPL.

## Совместимость и ограничения

- Windows 10/11;
- Microsoft Edge WebView2 Runtime;
- EXE не подписан коммерческим сертификатом, поэтому SmartScreen может показать предупреждение;
- поведение глобальной клавиши может зависеть от RDP, утилит клавиатуры и других программ с глобальными hooks.

Перед публикацией выпуск должен пройти автоматические тесты, Windows-сборку и ручную приёмку по `docs/WINDOWS_ACCEPTANCE.md`.

Полный список изменений находится в [CHANGELOG.md](CHANGELOG.md).
