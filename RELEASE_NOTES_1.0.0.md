# NumCalc 1.0.0

Первый стабильный выпуск компактного keyboard-first калькулятора для Windows.

## Главное

- вызов и скрытие окна клавишей NumLock без отключения цифрового блока;
- классический нативный ввод без экспериментальной анимации символов;
- live-preview, история, память, пользовательские переменные и их удаление;
- инженерный конвертер единиц;
- `*` отображается как `⋅`;
- `150(5)` отображается как `150⋅(5)` и вычисляется как неявное умножение;
- исправлен ввод цифрового блока вида `3100*.,1`;
- `Ctrl+C` копирует выражение вместе с результатом;
- `Alt+← / Alt+→` переключают калькулятор и единицы;
- single-instance, tray, автозагрузка, portable-режим и локальная диагностика;
- компактное окно `384×432`.

## Файлы выпуска

- `NumCalc.exe`;
- `NumCalc.exe.sha256.txt`.

Перед публикацией GitHub Release финальная сборка проверяется по `WINDOWS_ACCEPTANCE.md`.
