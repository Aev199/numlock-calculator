# NumCalc — ручная приёмка Windows

Версия для проверки: **1.3.0**  
Artifact: `NumCalc-1.3.0-windows-x64.zip` либо локальная сборка `build.bat`.

## 1. Запуск и оболочка

- [ ] `NumCalc.exe` запускается без установленного Python.
- [ ] В свойствах EXE указаны `NumCalc` и версия `1.3.0`.
- [ ] Повторный запуск не создаёт второй экземпляр.
- [ ] NumLock/назначенный hotkey показывает, фокусирует и скрывает окно без двойного срабатывания.
- [ ] Tray, About, ссылки и выход работают.
- [ ] Compact/full переключаются через `Alt+↑` / `Alt+↓`.

## 2. Базовая математика

- [ ] `2+3*4` → `14`.
- [ ] `(2+3)*4` → `20`.
- [ ] `sin(30)` в DEG → `0.5`.
- [ ] `9!` → `362880`.
- [ ] `200+10%` → `220`.
- [ ] `1/0` показывает понятную ошибку.
- [ ] `*` отображается как `⋅`, неявное умножение остаётся корректным.
- [ ] Точка и запятая принимаются как десятичный разделитель.
- [ ] Длинное выражение остаётся на одной строке и прокручивается горизонтально.

## 3. Переменные и пользовательские функции

- [ ] `x:=100` сохраняет переменную, `x` возвращает `100`.
- [ ] `c(d):=pi*d^2/4` сохраняет функцию.
- [ ] `c(20)` → `314.159265` при точности 6.
- [ ] `c(20 mm) to mm2` → `314.159265 mm2`.
- [ ] `r(a,b):=a*b`, затем `r(2,3)` → `6`.
- [ ] `r(2,5;3,5)` → `8.75`.
- [ ] При выборе функции из Tab-палитры вставляется `name()` и курсор находится внутри скобок.
- [ ] Функции видны в окне «Переменные и функции», удаление сохраняется после перезапуска.
- [ ] Пользовательская функция может читать обычную переменную и вызывать другую пользовательскую функцию.
- [ ] Рекурсивный вызов показывает ошибку.
- [ ] В интерфейсе отсутствует кнопка `Σ`; отдельные «Формулы» и «Профили» недоступны.

## 4. Арматурный shorthand

- [ ] `d16` → `2.010619 cm2`.
- [ ] `2d20` → `6.283185 cm2`.
- [ ] `2d20+d16` → `8.293805 cm2`.
- [ ] `d16s150` → `13.404129 cm2/m`.
- [ ] `4d20s200+d16s150` → `76.235982 cm2/m`.
- [ ] Десятичные значения и пробелы поддерживаются.
- [ ] `2d20+d16s150` не интерпретируется как shorthand.

## 5. История, память и копирование

- [ ] Enter добавляет одну запись истории.
- [ ] `↑ / ↓` перемещаются по истории.
- [ ] M0–M9 сохраняются и восстанавливаются.
- [ ] `Ctrl+C` копирует выражение и результат; для одного числа — только число.
- [ ] Поиск и удаление истории работают.

## 6. Единицы

- [ ] `2 м * 3 м` → `6 м²`.
- [ ] `2 кПа + 300 Па` → `2.3 кПа` либо эквивалент с запятой.
- [ ] `10 кН / 2 м²` → `5 кПа`.
- [ ] Несовместимые размерности отклоняются.
- [ ] Конвертер использует тот же формат результата.

## 7. Интерполяция

- [ ] `(0,0)`, `(10,100)`, `x=5` → `50`.
- [ ] `x=15` → `150`.
- [ ] Одинаковые `x0` и `x1` показывают ошибку.

## 8. DPI и стабильность

- [ ] Проверены 100%, 125%, 150% и 200% DPI.
- [ ] Заголовок не обрезается, dragging работает.
- [ ] Быстрые переключения режимов не оставляют две панели.
- [ ] После скрытия/показа фокус возвращается предсказуемо.
- [ ] В диагностике нет чувствительных пользовательских данных.
