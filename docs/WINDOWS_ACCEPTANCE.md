# NumCalc — ручная приёмка Windows

Версия для проверки: **1.3.0**  
Artifact: `NumCalc-windows-release` из GitHub Actions либо `NumCalc-1.3.0-windows-x64.zip` из release workflow.

Записывайте фактическую версию Windows, масштаб экрана, тип клавиатуры и результат каждого пункта. Блокирующий дефект означает, что GitHub Release `v1.3.0` не публикуется до исправления.

## 1. Архив, EXE и запуск

- [ ] SHA-256 ZIP совпадает с опубликованным `.sha256.txt`.
- [ ] Архив содержит `NumCalc.exe`, `NumCalc.exe.sha256.txt`, `LICENSE`, `LICENSING.md`, `THIRD_PARTY_NOTICES.md`, `RELEASE_NOTES.md` и каталог `licenses`.
- [ ] В `licenses/source` присутствует пакет `pystray-0.19.5`.
- [ ] EXE запускается без установленного Python.
- [ ] В свойствах EXE указаны имя `NumCalc` и версия `1.3.0`.
- [ ] В диспетчере задач остаётся один процесс приложения.
- [ ] При отсутствии WebView2 показывается понятная ошибка.
- [ ] Иконка `NumCalc.exe`, окна, панели задач и Alt+Tab совпадает с синей иконкой `N` в трее.
- [ ] При 0 знаков после запятой `123,6` округляется до `124`.
- [ ] При 4 знаках после запятой `12,3400` отображается как `12,34`, без хвостовых нулей.

## 2. «О программе» и ссылки

- [ ] Окно показывает `NumCalc 1.3.0`.
- [ ] Описание содержит формулировку «keyboard-first инженерный калькулятор».
- [ ] Присутствует атрибуция NumLock Calculator Владимира Потапова.
- [ ] Ссылка на оригинальный калькулятор открывает `https://nlcalc.narod.ru/`.
- [ ] Ссылка на репозиторий открывает `https://github.com/Aev199/numlock-calculator`.
- [ ] Произвольные схемы `file:` и `javascript:` не открываются.

## 3. Базовая математика и ввод

- [ ] `2+3*4` → `14`.
- [ ] `(2+3)*4` → `20`.
- [ ] `2^3^2` → `512`.
- [ ] `sin(30)` в DEG → `0.5`.
- [ ] `9!` вычисляется как `362880` и визуально показывается `362 880`.
- [ ] `200+10%` → `220`.
- [ ] `1/0` показывает «Деление на ноль».
- [ ] Незавершённое `2+` не создаёт запись истории.
- [ ] Ввод `*` отображается как `⋅`.
- [ ] `150(5)` отображается как `150⋅(5)` и даёт `750`.
- [ ] `(2)(3)` отображается как `(2)⋅(3)` и даёт `6`.
- [ ] `3100*.,1`, `3100*,1`, `3100⋅,1` и `3100⋅.1` дают `310`.
- [ ] Точка и запятая работают в русской и английской раскладках.
- [ ] Вложенные скобки отображаются по одной и различаются цветом.
- [ ] Поле ввода и строка результата используют один Windows UI-шрифт; цифры не меняют гарнитуру между редактором и результатом.
- [ ] При вводе `1000000` редактор показывает `1 000 000` и расчёт остаётся корректным.
- [ ] `60000*50` отображается как `60 000⋅50`, результат — `3 000 000`.
- [ ] `3000000,25` отображается как `3 000 000,25`, десятичный разделитель не повреждается.
- [ ] Каретка не прыгает в конец при появлении разделителя тысяч; вставка/удаление цифр внутри длинного числа остаётся предсказуемой.
- [ ] Разделители разрядов не добавляются внутрь имён переменных, единиц и экспоненты научной записи.
- [ ] Длинное выражение остаётся на одной физической строке и прокручивается горизонтально; длинное число не разрывается переносом.
- [ ] `d20s200` вычисляется как `15.707963 cm2` при точности 6.
- [ ] `4d20s200+d16s150` вычисляется как `76.235982 cm2` при точности 6.
- [ ] `2 d12,5 s 175 + d10 s200` принимается с пробелами и десятичной запятой и возвращает `cm2`.
- [ ] Обычное выражение с именем/переменной рядом с похожим текстом не распознаётся как арматурный shorthand, если вся строка не соответствует синтаксису.

## 4. История, копирование и фиксация результата

- [ ] Enter фиксирует результат и историю ровно один раз.
- [ ] Результат после Enter выделяется при включённой настройке.
- [ ] При отключённой настройке результат не выделяется.
- [ ] `↑` загружает предыдущее выражение с первого нажатия независимо от положения курсора.
- [ ] `↓` перемещается вперёд по истории и возвращает черновик.
- [ ] `Ctrl+C` копирует выражение и результат одной строкой.
- [ ] Для отдельного числа `Ctrl+C` копирует только число.
- [ ] Нажатие на запись истории возвращает исходное выражение в редактор.
- [ ] Длинные десятичные числа в истории визуально группируются по три цифры.
- [ ] Поиск и удаление записей работают без дублирования.

## 5. Размерностные выражения

- [ ] `2 м * 3 м` → `6 м²`.
- [ ] `2 кПа + 300 Па` → `2.3 кПа` либо эквивалент с запятой.
- [ ] `10 кН / 2 м²` → `5 кПа`.
- [ ] `2 м + 3 с` показывает ошибку несовместимых размерностей.
- [ ] `1 тс` корректно переводится в `9.80665 кН`.
- [ ] `1 тс/м²` корректно переводится в `9.80665 кПа`.
- [ ] Единицы результата согласованы между калькулятором и конвертером.
- [ ] Формат и десятичный разделитель применяются к размерностным результатам.
- [ ] Сгруппированный ввод вроде `1 000 кН / 2 м2` корректно вычисляется.

## 6. Формулы и инженерные профили

- [ ] Создаётся формула с названием, выражением, параметрами и значениями по умолчанию.
- [ ] Во вкладке «Формулы» понятно объяснены назначение формул и разница между «Запуск» и «Вставить».
- [ ] Во вкладке «Профили» понятно объяснены формулы профиля, константы, предпочтительные единицы и формат.
- [ ] Предварительный запуск формулы не изменяет обычные переменные калькулятора.
- [ ] Подтверждённый запуск формулы добавляет результат в общую историю.
- [ ] Создаётся профиль с константой и предпочтительными единицами.
- [ ] Активный профиль ограничивает список формул, если выбран непустой набор.
- [ ] Настройки округления профиля применяются к результату.
- [ ] После отключения профиля прежние единицы конвертера восстанавливаются.
- [ ] Формулы и профили сохраняются после перезапуска.

## 7. Конвертер единиц

- [ ] Категория, исходная и целевая единицы сохраняются после перезапуска.
- [ ] Результат калькулятора передаётся в «Единицы» только один раз на новую ревизию.
- [ ] `0 °C` → `273.15 K`.
- [ ] `1 g` → `9.80665 м/с²`.
- [ ] Поле принимает арифметику со скобками.
- [ ] Сгруппированный ввод `1 000 000 / 2` корректно принимается конвертером.
- [ ] `Ctrl+C` включает исходную и целевую единицы.

## 8. Линейная интерполяция

- [ ] Для `(x₀, y₀) = (0, 0)`, `(x₁, y₁) = (10, 100)`, `x = 5` получается `50`.
- [ ] Для `x = 15` выполняется экстраполяция и получается `150`.
- [ ] Расчёт запускается автоматически после заполнения всех полей.
- [ ] Кнопки «Рассчитать», «Очистить» и «Копировать» работают.
- [ ] Одинаковые `x₀` и `x₁` показывают понятную ошибку.
- [ ] Вся вкладка помещается в штатное окно без обязательного вертикального скролла.

## 9. Вкладки и анимации

- [ ] Доступны три вкладки: «Калькулятор», «Единицы», «Интерполяция».
- [ ] `Alt+→` циклически переключает вкладки вправо.
- [ ] `Alt+←` циклически переключает вкладки влево.
- [ ] Alt+стрелки не запускают навигацию WebView назад/вперёд.
- [ ] Индикатор заметно и плавно перемещается между вкладками.
- [ ] Содержимое меняется мягким затуханием без горизонтального выезда и изменения геометрии.
- [ ] Быстрые повторные переключения не оставляют две видимые панели.
- [ ] После переключения фокус попадает в правильное поле.
- [ ] `prefers-reduced-motion` отключает декоративное движение.

## 9a. Компактный режим

- [ ] В настройках доступен переключатель «Компактный режим».
- [ ] `Alt+↑` сворачивает полный интерфейс до compact.
- [ ] `Alt+↓` разворачивает compact до полного интерфейса.
- [ ] Старое сочетание `Ctrl+Shift+M` не перехватывается приложением.
- [ ] При включении остаётся только калькулятор; история, «Единицы», «Интерполяция» и переключатель вкладок не отображаются.
- [ ] При включении из «Единиц» или «Интерполяции» приложение возвращается в калькулятор.
- [ ] Высота compact подгоняется по фактическим `topbar + editor`; под результатом нет заметной пустой полосы.
- [ ] Изменение DPI/масштаба или высоты содержимого не возвращает фиксированное пустое место снизу.
- [ ] `Alt+←` / `Alt+→` не выводят из калькулятора, пока compact включён.
- [ ] `Ctrl+H` открывает всплывающую историю; повторный `Ctrl+H` и `Esc` её закрывают.
- [ ] `Esc` закрывает popup истории до обработки Escape полем калькулятора: выражение не очищается и приложение не скрывается.
- [ ] В popup истории работает поиск, стрелки перемещают фокус по записям, Enter загружает выбранное выражение.
- [ ] Кнопка «Копировать» в popup истории копирует результат.
- [ ] При открытии истории, настроек, палитры функций, памяти/переменных, формул или справки compact временно увеличивает высоту окна.
- [ ] После закрытия popup/drawer окно снова схлопывается ровно до калькулятора.
- [ ] Расчёты в compact продолжают добавляться в общую историю.
- [ ] После отключения compact возвращаются полный интерфейс и история, включая расчёты, сделанные в compact.
- [ ] При отключении восстанавливается нормальная высота полного окна.
- [ ] После перезапуска compact сохраняется и приложение сразу открывается маленьким, без вспышки полного layout.
- [ ] Проверены compact и popup истории на DPI 100%, 125%, 150% и 200%.

## 10. Глобальная клавиша, NumLock и фокус

- [ ] NumLock по умолчанию показывает, фокусирует и скрывает окно.
- [ ] Цифровой режим и LED остаются в ожидаемом состоянии.
- [ ] В настройках назначается другая допустимая комбинация.
- [ ] Конфликтующая или запрещённая комбинация отклоняется с понятным сообщением.
- [ ] Новая комбинация сохраняется после перезапуска.
- [ ] Возврат к NumLock работает.
- [ ] 20 быстрых вызовов не приводят к зависанию или дребезгу.
- [ ] После сна и блокировки Windows глобальная клавиша продолжает работать.
- [ ] RDP проверен, если входит в рабочий сценарий.

## 11. Память, переменные, tray и single-instance

- [ ] Запись и вставка `M0–M9` работают.
- [ ] `span := 6` создаёт переменную, `span / 2` даёт `3`.
- [ ] Переменная удаляется и не восстанавливается после перезапуска.
- [ ] Повторный запуск активирует существующее окно.
- [ ] Второй процесс, значок трея и hook не создаются.
- [ ] «Показать / Скрыть», «О программе», «Копировать диагностику» и «Выйти» работают.
- [ ] Автозагрузка не создаёт второй экземпляр.

## 12. Хранение, окно и диагностика

- [ ] Обычные данные сохраняются в `%LOCALAPPDATA%\NumCalc\data.json`.
- [ ] `portable.mode`, `--portable` и `NUMCALC_PORTABLE=1` включают portable-режим.
- [ ] При недоступной portable-папке используется профиль пользователя с предупреждением.
- [ ] Повреждённый JSON не блокирует запуск.
- [ ] Проверены DPI 100%, 125%, 150% и 200%.
- [ ] Текст не обрезается, элементы не накладываются.
- [ ] Название `NumCalc` полностью видно; последняя `c` не подрезана на проверяемых DPI.
- [ ] Окно остаётся доступным после отключения второго монитора.
- [ ] Создаётся `%LOCALAPPDATA%\NumCalc\logs\numcalc.log`.
- [ ] Лог содержит версию 1.3.0, среду, режим hook и путь данных.
- [ ] Диагностика не содержит телеметрии и чувствительных выражений пользователя.
