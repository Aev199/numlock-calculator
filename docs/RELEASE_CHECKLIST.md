- [x] `c(d):=pi*d^2/4` сохраняется как пользовательская функция.
- [x] Поддерживаются функции с несколькими параметрами.
- [x] Функции сохраняются, появляются в Tab-палитре и окне «Переменные и функции».
- [x] Вставка функции создаёт `name()` с курсором внутри.
- [x] Поддерживаются единицы, текущие переменные и вложенные пользовательские функции.
- [x] Рекурсия и зарезервированные имена блокируются.
- [x] Старый backend/API сохранённых формул и инженерных профилей удалён из рабочего пути.
- [x] Кнопка `Σ` скрыта; старый drawer и guidance не доступны пользователю.
- [x] Добавлены `d16`, `2d20`, `d16s150`, суммы через `+`.
- [x] Длинный ввод не переносится и имеет горизонтальную прокрутку.
