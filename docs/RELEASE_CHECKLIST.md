## 2. Функциональность 1.3.0

- [x] Добавлена запись без шага: `d16`, `2d20`, суммы через `+`.
- [x] Запись без `s` возвращает суммарную площадь стержней в `cm2`.
- [x] Добавлена запись с шагом: `d16s150`, `4d20s200+d16s150`.
- [x] Запись с `s` возвращает площадь армирования на метр в `cm2/m`.
- [x] Диаметр и шаг интерпретируются в миллиметрах.
- [x] Необязательное число перед `d` задаёт количество одинаковых стержней либо слоёв/наборов.
- [x] Термины с шагом и без шага нельзя смешивать в одном shorthand-выражении.
- [x] Shorthand активируется только при полном соответствии всей строки.
- [x] Основной редактор не переносит длинные выражения, имеет `wrap="off"` и горизонтальную прокрутку.
- [x] Добавлены регрессионные тесты для арматуры и CSS/HTML-контракта длинного ввода.
