## 2. Функциональность 1.3.0

- [x] Добавлена запись `dDsS` для площади арматуры.
- [x] Поддержан необязательный множитель слоёв/наборов перед `d`.
- [x] Поддержаны суммы арматурных терминов через `+`.
- [x] Диаметр и шаг интерпретируются в миллиметрах.
- [x] Итог явно переводится в `cm2`.
- [x] Shorthand активируется только при полном соответствии всей строки.
- [x] Основной редактор не переносит длинные выражения и использует горизонтальную прокрутку.
- [x] Добавлены регрессионные тесты для арматуры и CSS-контракта длинного ввода.
