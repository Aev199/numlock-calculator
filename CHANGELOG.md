# Changelog

Все значимые изменения NumCalc фиксируются в этом файле.

## 1.0.0 — 2026-07-28

### Добавлено

- единое название продукта **NumCalc** и централизованная версия;
- Windows single-instance guard: повторный запуск активирует существующее окно;
- локальная вращаемая диагностика без телеметрии;
- пункт трея **«Копировать диагностику»**;
- обычное хранилище в `%LOCALAPPDATA%\NumCalc\data.json`;
- явный portable-режим через `portable.mode`, `--portable` или `NUMCALC_PORTABLE=1`;
- автоматическая миграция старого JSON, лежащего рядом с EXE;
- ограничения длины и сложности AST-выражений;
- отдельный инженерный конвертер единиц;
- удаление сохранённых пользовательских переменных из окна переменных;
- Windows CI job, собирающий EXE и SHA-256 artifact;
- Windows version resource для свойств `NumCalc.exe`.

### Изменено

- физический ввод `*` отображается в редакторе и истории как `⋅`;
- неявное умножение отображается явно: `150(5)` → `150⋅(5)`;
- `Ctrl+C` копирует выражение и результат одной строкой, но для единственного числа копирует только само значение;
- `Alt+← / Alt+→` переключают вкладки «Калькулятор» и «Единицы»;
- интерфейс адаптирован под компактное окно `384×432`;
- сборочный результат переименован в `NumCalc.exe`;
- CI запускается при push в `main`;
- сборочные сценарии автоматически создают SHA-256.

### Исправлено

- ввод `3100*.,1`, `3100*,1`, `3100⋅,1` и аналогичные последовательности интерпретируются как корректная десятичная дробь;
- frontend-ошибки и необработанные Promise записываются в локальную диагностику;
- второй экземпляр больше не создаёт дублирующий NumLock-hook, tray и конкурирующую запись JSON;
- приложение не прекращает запуск при недоступности основной папки логов;
- при недоступности portable-папки выбирается доступное резервное хранилище с предупреждением;
- размеры внутренних элементов согласованы с компактным размером окна;
- палитра функций больше не расходует место на постоянную подсказку, а длинные группы прокручиваются внутри доступной высоты окна;
- цветные скобки сохраняют уровни вложенности и больше не дублируются после перехода к компактной плотности интерфейса.

### Решение для релиза

- экспериментальная анимация появления символов полностью исключена;
- поле выражения использует классический нативный ввод WebView2 без визуальной подмены текста.
