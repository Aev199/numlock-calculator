# Changelog

Все значимые изменения NumCalc фиксируются в этом файле.

## Unreleased

Изменений после подготовки 1.4.2-beta.2 пока нет.

## 1.4.2-beta.2 — 2026-10-19

### Исправлено

- окно больше не вспыхивает белым при переходе между компактным и обычным режимом и при открытии настроек, палитры и справки в компактном режиме;
- в компактном режиме палитра функций снова управляется клавиатурой, а Escape закрывает её, не пряча калькулятор (ошибка 1.4.2-beta.1);
- бета-версия больше не считается равной одноимённой финальной, а `beta.2` — равной `beta.1`, поэтому новые сборки приходят и тем, кто ставил бету.

### Удалено

- анимация переключения компактного режима и появления окон из 1.4.2-beta.1: переключение снова мгновенное.

## 1.4.1 — 2026-10-19

### Исправлено

- NumCalc 1.4.0 не запускался, если лежал не на том диске, где папка временных файлов Windows (например, на `D:` или флешке);
- ошибка в проверке обновлений больше не может помешать запуску калькулятора.

## 1.4.0 — 2026-10-19

### Добавлено

- обновление из приложения: NumCalc сам находит новую версию, проверяет контрольную сумму и заменяет `NumCalc.exe`, прежняя версия остаётся для отката;
- каналы обновлений: стабильные выпуски или все сборки, включая бета;
- обновление без прямого доступа к GitHub: через общую папку в сети или файл, скачанный в браузере;
- значок обновления в заголовке, раздел «Обновления» в настройках и пункт «Проверить обновления» в трее.

### Изменено

- единицы в результатах записываются по-русски: `кН·м`, `см²`, `кПа`, `мм²`;
- `10 m · 3 kN` даёт `30 кН·м`, а `16 mm · 16 mm` остаётся в `мм²`;
- кнопки в заголовке и над строкой ввода без рамок, иконки нарисованы одним набором;
- «Память» показывает только занятые ячейки;
- палитра функций показывает описания функций;
- история, память и интерполяция набраны тем же шрифтом, что и строка ввода;
- тексты интерфейса стали короче, настройки сохраняются без сообщений об успехе;
- новая иконка приложения без зазубрин.

### Исправлено

- ошибка вычисления занимает одну строку;
- в «Единицах» перенесённое значение выделяется и заменяется вводом;
- Escape закрывает «Память», «Переменные» и «Настройки» и не очищает строку ввода;
- окно справки больше не пропускает Tab в палитру функций.

## 1.3.0 — 2026-08-25

### Добавлено

- лёгкие пользовательские функции прямо в строке калькулятора: `c(d) := pi*d^2/4`;
- функции с несколькими параметрами: `r(a,b) := a*b`;
- сохранение пользовательских функций в `engine_state`, интеграция с Tab-палитрой и окном «Переменные и функции»;
- автоматическая вставка `name()` с курсором внутри скобок;
- инженерный shorthand площади стержней: `d16`, `2d20`, `2d20+d16`;
- shorthand площади армирования на метр: `d16s150`, `4d20s200+d16s150`;
- регрессионные тесты пользовательских функций и арматурного синтаксиса.

### Изменено

- арматурная запись использует существующий безопасный AST-движок и реестр единиц;
- длинное выражение остаётся на одной физической строке и прокручивается горизонтально;
- GitHub Actions переведены в минимальный режим: PR запускает только тесты, release workflow — только вручную или по тегу.

### Удалено

- отдельная библиотека сохранённых «Формул»;
- инженерные «Профили», их константы, фильтрация формул, предпочтительные единицы и отдельный drawer;
- справка и пользовательский интерфейс старого механизма формул/профилей.

Для коротких повторяемых расчётов вместо удалённого механизма используются пользовательские функции.

### Исправлено

- длинные числовые токены больше не переносятся внутри поля ввода;
- тест release workflow приведён к текущей политике без `pull_request`;
- тест пользовательских функций больше не использует зарезервированное имя единицы `k`.

## 1.2.0 — 2026-08-11

- добавлены размерностные выражения, инженерные единицы, настраиваемая глобальная клавиша, интерполяция и compact-режим;
- в этой версии также существовали сохранённые формулы и инженерные профили; в 1.3.0 они удалены.

## 1.0.0 — 2026-07-28

- первый публичный выпуск NumCalc;
- single-instance, локальная диагностика, portable storage, инженерный конвертер, Windows packaging и public release workflow.
