# NumCalc 1.0.0 release checklist

## Автоматическая проверка

- [x] Linux CI: компиляция активных Python-модулей.
- [x] Linux CI: полный `unittest discover`.
- [x] Linux CI: `node --check` собранного renderer.
- [x] Windows CI: полный `unittest discover`.
- [x] Windows CI: PyInstaller создаёт `dist\NumCalc.exe`.
- [x] Windows CI: создан и опубликован SHA-256.
- [ ] Свойства финального EXE содержат `NumCalc 1.0.0`.
- [x] Экспериментальная анимация ввода отсутствует в CSS, JavaScript и сборочном списке.

Последняя автоматическая проверка должна оставаться зелёной после каждого изменения release-ветки.

## Ручная приёмка

- [ ] Полностью пройден `WINDOWS_ACCEPTANCE.md` на финальной сборке 1.0.0.
- [ ] Проверена Windows 10 либо зафиксировано «не применимо».
- [ ] Проверена Windows 11.
- [ ] Проверены NumLock-hook, tray, single-instance и автозагрузка.
- [ ] Проверены DPI 100%, 125%, 150% и 200%.
- [ ] Проверены обычное и portable-хранилища.
- [ ] Проверены `Ctrl+C`, `Alt+←/→`, `* → ⋅`, `150(5)` и ввод `3100*.,1`.
- [ ] Проверено создание, использование и удаление пользовательской переменной.
- [ ] Подтверждён классический ввод без мерцания и дополнительных эффектов.
- [ ] В диагностике нет чувствительных пользовательских данных сверх выражений/ошибок, добавленных самим пользователем.

## Выпуск

- [x] Экспериментальная анимация исключена из релизного кода.
- [x] `APP_VERSION` изменена с `1.0.0-rc.1` на `1.0.0`.
- [x] Перегенерирован `version_info.txt`.
- [x] Обновлён `CHANGELOG.md` для 1.0.0.
- [ ] Финальный EXE собран из проверенного коммита.
- [ ] SHA-256 опубликован рядом с финальным EXE.
- [ ] Все блокирующие дефекты закрыты по итогам финальной ручной проверки.
- [ ] Создан GitHub Release `v1.0.0`.
